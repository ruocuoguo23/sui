# Consensus simulator support

This crate wraps the pinned Mysten simulator for Dagora's consensus tests. With
`cfg(msim)`, it exposes the simulator runtime, network and node APIs, latency
configuration helpers, deterministic random helpers, and the current node ID.
`NodeLeakDetector` supports the cleanup checks generated by `sui-macros`.

Run from the repository root with `cargo-nextest` installed:

```bash
MSIM_TEST_SEED=1 scripts/simtest/cargo-simtest simtest \
  -p consensus-simtests --profile ci --test-threads 1
```

The runner applies the pinned Tokio and futures-timer patches, enables
`cfg(msim)`, and restores the original workspace lockfile after the run. Run
Cargo commands sharing this workspace serially.

See the [simulator tools guide](../../scripts/simtest/README.md) for installation,
seed searches, determinism checks, and lockfile recovery. The broader upstream
Sui simulator guide is retained in the
[source reference archive](../../upstream/sui/crates/sui-simulator/README.md).
